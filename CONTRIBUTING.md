# Contributing

Thanks for taking an interest in this research.

This repository currently prioritizes accurate documentation and reproducible observations over publishing a ready-to-install game package.

## Useful contributions

- Review technical descriptions for accuracy.
- Suggest instrumentation for UIKit, Metal, Unreal viewport sizing or input routing.
- Help distinguish upstream behavior from Stray-specific modifications.
- Report documentation errors with evidence and version context.

## Please do not submit

- Stray binaries, PAK files, extracted assets, IPA files or converted application bundles.
- Signing certificates, provisioning profiles, private keys, device identifiers or unredacted logs.
- Code copied from other projects without clear provenance and compatible licensing.

## Reporting a result

Include device model and OS version, Mac and Xcode/SDK versions, exact milestone, steps, redacted logs or screenshots, and expected versus observed behavior. Do not describe a feature as working unless verified on-device.
